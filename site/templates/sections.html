Reproducibility / The method

How matching works

Readable source is the start.
Matching the original is the test.

MATCHING PROTOCOL

Pin the input SHA-256, architecture and compiler. Establish a complete function boundary before selecting anything to compare.

verify-targets → inspect → prove the boundary
⌖

Two checks, clearly separated. Local matching requires the pinned binary and compiler. The current certifier supports complete constant-return leaves; other functions need verified boundaries and reference handling. Public CI checks published source, header, gate and target hashes and runs fixture tests. It does not rebuild the private game binaries.

Research / The CN connection

CN and Steam research

The CN build exposes a rich set of named Wasm host callbacks. These give us footholds: known API contracts, shared exports and candidate native helpers to investigate.

The Wasm module is a skill and hotfix layer. The native engine is much larger, and an identical name does not prove identical behavior.

The research report / Milestones

Research roadmap

Milestones describe deliverables.
They are not a percentage of the engine.

  1. ✓
    Established

    Make the first exact match

    Pin the builds, compile real C++, verify a complete body, and prove the gate rejects a changed result.

  2. 02
    In progress

    Map the shared foundations

    Use CN contracts to identify small helpers. Recover types and boundaries, then grow the verified unit ledger.

  3. 03
    Planned

    Rebuild larger units

    Establish a CN compiler recipe, study link-dependent code, and add relocation-aware object and link comparison.

  4. 04
    Long term

    Account for the whole engine

    Expand the translation-unit inventory, define measurable coverage, and work toward a reproducible complete build.

The evidence standard

What the numbers mean.

VerifiedExact function bodies+

Compiled source matched the entire independently established native range. Source and target hashes identify precisely what was checked. A changed pilot was rejected by the gate: checking receipt.

ObservedNative references & contracts+

The reviewed selector table recovered — card IDs absent from the earlier comparison view. These are decoded references, not newly certified effects, new releases, or restored C++ functions.

UnresolvedWhole-engine coverage+

The total function inventory, original build recipes and full runtime behavior remain unresolved. No overall completion percentage is published until a defensible denominator exists.
